Personality & voice

Let Nova add an occasional aside. Agent status stays visual; only quips use voice.

Ordinary cloud requests send a status cue, personality, language, your saved notes, and recent direct conversations with Nova to OpenAI. They do not read other agents’ transcript files. Optional window vision can also send the selected window image when separately enabled; see its controls below. Each attempt reserves a conservative model-dependent amount locally, including previews and failures. This estimate is not a provider billing cap; set a provider-side limit too. Daily counters reset at midnight Pacific time.

Saved with OS encryption. The key is never returned to the settings page. Cloud requests stay off until enabled above.

Optional window vision is off by default. Enabling it allows Nova to send a small capture of the window she is peeking behind to OpenAI; that image may contain private information visible in the app. Captures are not saved to disk or companion memory. Fullscreen windows, unavailable windows, and excluded apps are skipped. Ordinary agent updates and direct chat do not capture images.

Chat & memory

Nova stores her last 100 chat entries and remarks with OS encryption. The latest eight entries and your personal notes accompany model requests. A pet-sized memory, separate from your other agents.
